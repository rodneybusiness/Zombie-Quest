# Beta Playtest Protocol — v0.9.0-beta

Thanks for testing. Budget ~20 minutes. Don't read the walkthrough first —
we need your blind first impressions.

## Setup

- macOS/Linux: `./run_game.sh` · Windows: `run_game.bat`
- Requires Python 3.9+; the launcher installs pygame if missing.
- Problems launching? Note your OS + Python version and stop there — that's
  a finding.

## Controls

- **Left click**: act with the selected verb (walk / look / use / talk)
- **Right click or 1-4**: switch verbs · **I**: inventory · **P**: pause
- **WASD/arrows**: walk · **F11**: fullscreen · **Esc** (on ending): quit

## Session script

1. Play cold for 10 minutes. Say aloud (or note) anything confusing.
2. Goal, if you need one: get backstage at First Avenue and find Maya.
3. If you die/turn: note how it felt (fair? cheap?), then keep going —
   you respawn at the checkpoint.
4. Stop at 20 minutes or an ending, whichever comes first.

## Known issues (don't report these)

- No title screen yet — the game opens directly on Hennepin Avenue.
- Infection vein/vignette overlays are not yet palette-locked.
- Audio mix is a first pass; music layers can pop on room change.
